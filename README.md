# 🚀 FFy

A React Application Built With **React + Vite**.

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- Node.js
- npm

## 📋 Requirements

Before Running This Project, Make Sure You Have:

- **Node.js**
- **npm**
- **Git**

You Can Check Them Using:

```bash
node --version
npm --version
git --version
```

## 📥 Installation

### 1. Clone The Repository

```bash
git clone "https://github.com/ferrofy/FFy.git"
```

### 2. Open The Project Folder

```bash
cd FFy
```

### 3. Install Dependencies

```bash
npm install
```

This Will Automatically Download And Create The `node_modules` Folder Using The Dependencies Listed In `package.json`.

### 4. Start The Development Server

```bash
npm run dev
```

Vite Will Show A Local URL Such As:

```text
http://localhost:5173/
```

Open That URL In Your Browser.

## 🏗️ Build For Production

To Create A Production Build:

```bash
npm run build
```

The Production Files Will Be Generated Inside:

```text
dist/
```

## 👀 Preview Production Build

```bash
npm run preview
```

## 📜 Available Commands

| Command | Purpose |
|---|---|
| `npm install` | Install Dependencies |
| `npm run dev` | Start Development Server |
| `npm run build` | Create Production Build |
| `npm run preview` | Preview Production Build |
